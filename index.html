Estrutura de pastas

Como o projeto está organizado no disco

A organização do LuxBeautiful

LuxBeautiful/
├── index_iara.html    ← home
├── contato.html       ← página de contato
├── produtos.html      ← lista de produtos (em branco ainda)
├── prod1.html         ← produto individual (em branco)
├── css/
│   └── layout_iara.css
└── imgs/

Arquivos .html ficam na raiz. CSS vai em css/. Imagens em imgs/. Simples e direto.

Caminhos relativos

Quando um arquivo referencia outro, usa o caminho a partir de onde ele mesmo está.

<!-- Do HTML (na raiz), o CSS está em: -->
href="css/layout_iara.css"

/* Do CSS (dentro de css/), a imagem está em: */
url('../imgs/banner.png')
/* ".." = sobe um nível (sai de css/) antes de entrar em imgs/ */
Sempre use barra normal /. Barra invertida \ só funciona no Windows — na web quebra.

Esqueleto HTML

A base de toda página web

O código mínimo obrigatório

<!DOCTYPE html>              <!-- "use HTML5" -->
<html lang="pt-br">           <!-- idioma da página -->
<head>
  <meta charset="UTF-8">      <!-- permite ã, ç, é etc -->
  <meta name="viewport"
        content="width=device-width, initial-scale=1.0"> <!-- ajusta para celular -->
  <title>LuxBeautiful</title>  <!-- texto na aba do navegador -->
  <link rel="stylesheet" href="css/layout_iara.css">
</head>
<body>
  <!-- tudo que o usuário VÊ fica aqui -->
</body>
</html>

Extras usados no projeto

<!-- Ícone na aba (favicon) -->
<link rel="shortcut icon" href="imgs/cosmeticos.png" type="image/x-icon">

<!-- Fonte externa do Google Fonts -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Cinzel...">

<!-- Biblioteca de ícones -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap-icons...">
preconnect avisa o navegador para já conectar ao servidor do Google antes de precisar dos arquivos — carrega mais rápido.

Tags semânticas

HTML com significado real

Por que usar tags semânticas?

Antes do HTML5, tudo era <div>. As tags semânticas não mudam a aparência — elas dizem o que cada bloco representa, ajudando buscadores e leitores de tela.

TagSignificaOnde aparece no projeto
<main>Conteúdo principalEnvolve o menu e todo o conteúdo
<nav>Área de navegaçãoO menu com os links
<section>Seção temáticaLançamentos, Destaques, Promoções…
<header>CabeçalhoTopo da página de contato
<footer>RodapéE-mail e telefone no final
<div>Agrupamento genéricoAgrupamentos visuais sem significado especial

A hierarquia do index_iara.html

<main>
  <nav>  <!-- menu -->  </nav>
  <div class="conteudo">
    <section class="banner">...</section>
    <section id="lancamentos">...</section>
    <section id="destaques">...</section>
    <section id="promocoes">...</section>
    <section id="vendedoras">...</section>
  </div>
</main>
<footer>...</footer>

class vs id — e âncoras

Como identificar e navegar entre elementos

classid
Símbolo no CSS.nome#nome
Pode repetir?Sim — vários elementos podem ter a mesma classeNão — só um por página
Uso principalEstilo visual reutilizávelÂncoras de navegação e JavaScript

Âncoras — rolar até uma seção

<!-- No menu: link que rola até a seção -->
<a href="#lancamentos">Lançamentos</a>

<!-- Na página: a seção com o id correspondente -->
<section id="lancamentos">...</section>
O botão "Ver lançamentos" do banner usa href="#lancamentos" para rolar suavemente até aquela seção. O CSS activa isso com html { scroll-behavior: smooth; }.

Links, imagens e ícones

<a>, <img> e Bootstrap Icons

Tag <a>

<!-- Outra página -->
<a href="contato.html">Contato</a>

<!-- Âncora (mesma página) -->
<a href="#lancamentos">Ver lançamentos</a>

<!-- Site externo: target="_blank" abre em nova aba -->
<a href="https://site.com" target="_blank">Externo</a>

Tag <img>

<img src="imgs/creme_dior.avif" alt="Creme Dior">
  • src — caminho da imagem
  • alt — texto alternativo; aparece se a imagem não carregar e é lido por leitores de tela
Nunca omita o alt. Se a imagem for só decoração, use alt="".

Bootstrap Icons

Após carregar a biblioteca no <head>, cada ícone é uma simples tag <i>:

<i class="bi bi-house"></i>        <!-- 🏠 -->
<i class="bi bi-envelope-fill"></i> <!-- ✉️ -->
<i class="bi bi-whatsapp"></i>    <!-- 💬 -->
No menu, cada link tem um ícone + texto em <span>. No tablet, o CSS oculta o <span> (display:none) e deixa só o ícone — economiza espaço sem mudar o HTML.

CSS — variáveis, reset e box model

A base do estilo do projeto

Variáveis CSS — :root

Define valores reutilizáveis em um só lugar. Se mudar a cor principal, muda em um lugar e atualiza o site todo.

:root {
  --bg-cor-escura:     #cb8e7d;
  --bg-secao:          rgb(252, 211, 194);
  --cor-destaque:      #fd0101;
  --texto-claro:       #fdf9f9;
  --fonte-padrao:      'Lato', Arial, sans-serif;
  --fonte-titulo:      'Cinzel', serif;
  --altura-menu:       70px;
  --borda-arredondada: 12px;
}

/* Usar a variável: */
.footer { background-color: var(--bg-cor-escura); }

Reset CSS

Navegadores têm estilos padrão diferentes. O reset zera tudo para ter controle total.

* {
  margin: 0;
  padding: 0;
  box-sizing: border-box; /* padding incluso no tamanho definido */
}
box-sizing: border-box — se você define width: 200px, o padding fica dentro desses 200px. Sem isso, o padding seria somado por fora e o elemento ficaria maior que o esperado.

Box Model — as 4 camadas de todo elemento

margin   → espaço externo (afasta outros elementos)
border   → borda visível
padding  → espaço interno (entre borda e conteúdo)
content  → o conteúdo em si (texto, imagem…)

.cartao {
  padding: 16px;
  border-radius: 12px;       /* arredonda os cantos */
  box-shadow: 0 4px 18px rgba(0,0,0,0.08); /* sombra */
}

Flexbox

O sistema de layout de quase tudo no projeto

Ativa com display: flex no contêiner. Os filhos diretos viram "itens flex" e se organizam automaticamente em linha ou coluna.

Propriedades usadas no projeto

PropriedadeO que fazOnde
flex-direction: rowItens em linha (padrão)Menu, cartões no desktop
flex-direction: columnItens empilhadosMenu mobile, cartões no celular
justify-content: space-betweenEmpurra primeiro e último para as pontasMenu (logo à esquerda, links à direita)
align-items: centerCentraliza no eixo cruzadoMenu (itens alinhados verticalmente)
gap: 20pxEspaço entre os itensCartões, links do menu
flex: 1O item cresce para preencher o espaçoColunas do formulário de contato
flex-wrap: wrapItens podem quebrar para a linha seguinteCartões no tablet

Exemplo: menu e cartões

.menu {
  display: flex;
  align-items: center;
  justify-content: space-between; /* logo esq, links dir */
}

.cartoes {
  display: flex;
  flex-direction: column; /* mobile: empilhados */
  gap: 20px;
}
/* No desktop vira linha (ver módulo 12) */

Position

Menu fixo e overlay do banner

ValorComportamento
staticPadrão. Segue o fluxo normal.
relativeNo fluxo, mas permite deslocamento. Serve de referência para filhos absolute.
absoluteSai do fluxo. Posiciona-se em relação ao pai com position não-static mais próximo.
fixedSai do fluxo. Prende-se à janela — não move ao rolar.

Menu fixo no topo

.menu {
  position: fixed;
  top: 0;
  z-index: 999; /* fica na frente de todo o conteúdo */
}

/* Como o menu é fixed (fora do fluxo), o conteúdo ficaria
   embaixo dele. Solução: empurrar com padding-top: */
.conteudo {
  padding-top: var(--altura-menu); /* = 70px */
}

Overlay do banner

A camada escura sobre a imagem do banner é criada com CSS puro, sem nenhuma <div> extra no HTML:

.banner {
  position: relative; /* referência para o filho absolute */
  background-image: url('../imgs/banner.png');
}

.banner::before {  /* camada escura (pseudo-elemento) */
  content: '';
  position: absolute;
  inset: 0;  /* = top:0; right:0; bottom:0; left:0 */
  background-color: rgba(0,0,0,0.35);
}

.banner-texto {
  position: relative;
  z-index: 1; /* texto fica na frente do overlay */
}

Pseudo-elementos ::before e ::after

Conteúdo criado pelo CSS sem tocar no HTML

::before insere um conteúdo antes do elemento. ::after insere depois. São usados para decoração que não precisa estar no HTML.

Sempre exigem content: '' para existirem — mesmo que o conteúdo seja vazio.

Linha decorativa após os títulos

.sessao h2 {
  display: flex;
  align-items: center;
  gap: 12px;
}

.sessao h2::after {
  content: '';
  flex: 1;  /* ocupa todo o espaço que sobrar */
  height: 2px;
  background: linear-gradient(to right, #cb8e7d, transparent);
}
É a linha rosa que aparece ao lado de "Lançamentos", "Destaques" etc., desbotando para a direita. Zero HTML extra.

Transições e :hover

Animações suaves na interação

:hover e transition

:hover define estilos que só valem quando o mouse está sobre o elemento. transition anima a mudança em vez de ser instantânea.

.cartao {
  /* declara a transição no estado normal */
  transition: transform 0.25s ease, box-shadow 0.25s ease;
}

.cartao:hover {
  transform: translateY(-5px);  /* sobe 5px */
  box-shadow: 0 12px 28px rgba(0,0,0,0.12);
}
A transition fica no estado normal do elemento, não no :hover. Assim a animação funciona tanto na entrada quanto na saída do hover.

Zoom na foto das vendedoras

.vendedora-foto-wrap {
  overflow: hidden; /* esconde o que "vaza" no zoom */
}
.vendedora-foto-wrap img {
  transition: transform 0.4s;
}
.cartao-vendedora:hover .vendedora-foto-wrap img {
  transform: scale(1.05); /* zoom de 5% */
}
O hover é detectado no card inteiro (.cartao-vendedora), mas o efeito é aplicado na imagem lá dentro. CSS permite selecionar um filho com base no estado do pai assim.

Responsividade — @media queries

Um site para qualquer tamanho de tela

Media queries aplicam estilos diferentes conforme a largura da tela.

/* Só vale quando a tela tem 768px ou menos */
@media (max-width: 768px) {
  .menu { ... }
}

Os 4 breakpoints do projeto

CondiçãoAlvoO que muda
min-width: 992pxDesktopCartões em linha
max-width: 1024pxTabletMenu mostra só ícones (texto some)
max-width: 768pxMobileMenu vira barra flutuante na parte inferior
max-width: 430pxCelular pequenoCartões ocupam 100% da largura

O menu mobile — a parte mais criativa do projeto

@media (max-width: 768px) {
  .menu {
    position: fixed;
    bottom: 14px;            /* vai para baixo */
    left: 50%;
    transform: translateX(-50%); /* centraliza */
    width: 92%;
    border-radius: 20px;
    flex-direction: column;
  }
  /* Menu fechado: lista desaparece */
  .menu.menu-collapsed ul {
    max-height: 0;
    opacity: 0;
    pointer-events: none;
  }
}
left: 50% + transform: translateX(-50%) é a técnica clássica para centralizar um elemento com position: fixed.

JavaScript

Funções, DOM e eventos

HTML = estrutura. CSS = aparência. JS = comportamento. No projeto, o JS faz duas coisas: valida o formulário e controla o menu mobile.

Validação do formulário

function enviar() {
  // .getElementById busca o elemento pelo id
  // .value lê o que o usuário digitou
  // .trim() remove espaços vazios nas pontas
  const nome     = document.getElementById('nome').value.trim();
  const email    = document.getElementById('email').value.trim();
  const mensagem = document.getElementById('mensagem').value.trim();

  // ! = negação. !nome é verdadeiro se nome estiver vazio
  if (!nome || !email || !mensagem) {
    alert('Preencha nome, e-mail e mensagem.');
    return; // para aqui se algum campo estiver vazio
  }

  alert('Mensagem enviada!');
}

Controle do menu mobile

const menu       = document.getElementById('menu');
const menuToggle = document.getElementById('menuToggle');

// addEventListener: "quando clicar no botão, executa esta função"
menuToggle.addEventListener('click', () => {
  // classList.toggle: adiciona a classe se não existir, remove se existir
  menu.classList.toggle('menu-collapsed');
});
O JS só adiciona/remove a classe menu-collapsed no menu. Quem de fato esconde a lista é o CSS: .menu.menu-collapsed ul { max-height: 0; opacity: 0 }. JS e CSS trabalham juntos.

Duas formas de conectar JS ao HTML

<!-- 1. Atributo direto no HTML (simples, usado no botão Enviar) -->
<button onclick="enviar()">Enviar</button>

<!-- 2. addEventListener no JS (mais moderno e organizado) -->
elemento.addEventListener('click', função);
